This is an [Astro](https://astro.build/) project, using React components as interactive islands.

## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) with your browser to see the result.

You can start editing the page by modifying `pages/index.astro` and `components/home.tsx`.
